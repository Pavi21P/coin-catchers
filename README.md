# Coin Catchers

A 2D Unity platformer with coin collection, enemies, ladders, shooting, and three levels.

## Open the project

1. Clone or download this repository.
2. Install **Unity 2022.3.62f2** through Unity Hub.
3. In Unity Hub, add the repository folder as a project and open it. Allow Unity to restore packages and import assets.
4. Open `Assets/Scenes/TitleScreen.unity` and press Play.

The build scene order is TitleScreen, Level 1, Level 2, and Level 3. The project uses the Universal Render Pipeline and Unity Input System.

## Controls

- **A/D** or **Left/Right arrows**: move.
- **W/S** or **Up/Down arrows**: climb ladders.
- **Space**: jump.
- **Left mouse button** or **Enter**: shoot.

## Repository contents

`Assets/`, `Packages/`, and `ProjectSettings/` contain the Unity project. Generated caches, builds, and local editor settings are excluded. This repository contains project source; open it in Unity to play or create a build.
